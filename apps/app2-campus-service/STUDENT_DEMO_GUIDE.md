## robot.jsx 顯示端

`robot_app2.jsx`（位於 `legacy/robot_app2.jsx`）透過 `robot-display-entry.tsx` 掛載在 `/robot-display.html`。

### 連線方式

第二螢幕 / iPad 直接輸入網址：
```
http://<主控機 LAN IP>:5174/robot-display.html
```

生產環境會在右下角出現提示：`投影 URL: {origin}/#robot`，代表評審可以用這台主機的 IP 連入。

### 機器人自動更新情緒

`buildRobotDisplayCue(state)` 把 App state 轉成情緒指令。Bridge server（port 3202）收到後用 WebSocket 推送給 `/robot-display.html`，`robot_app2.jsx` 即時更新動畫表情：

| App 狀態 | 機器人表情 |
|---|---|
| 緊急封控啟動 | 哭哭 / 生氣 |
| AI 點名完成 | 開心 |
| 配送進行中 | 思考 |
| 三閉環全完成 | 愛心 |
| 待機 | 平靜 |

### 手動控制

右下角 FAB 按鈕「🎮 手動遙控」→ 虛擬搖桿 + ExternalRobotPanel：

| 操作 | 指令 | 硬體動作 |
|---|---|---|
| 搖桿上 | FORWARD | M1+M2 正轉 |
| 搖桿下 | BACKWARD | M1+M2 反轉 |
| 搖桿左 | LEFT | M1 慢 / M2 快 |
| 搖桿右 | RIGHT | M1 快 / M2 慢 |
| 放開 | STOP | 全部停止 |
| 清掃開 | SWEEP_ON | M3+M4 啟動 |
| 清掃關 | SWEEP_OFF | M3+M4 停止 |

## 評審可能會問

### 影像辨識是不是假的？

不是。按「立即開始 AI 掃描」後，App 用 canvas 截取即時鏡頭畫面（JPEG），送到 Gemini 2.5 Flash Vision，  
回傳結果包含出席人數、出席率、信心值，以及「分心」或「提問」訊號。  
如果網路不穩，App 自動顯示「離線備援模式」，用本機分析接手，閉環不中斷。

### 這是不是只有按鈕切頁？

不是。主要操作會同步改變：
- `state.orders`（庫存、訂單、數量）
- `state.tasks`（任務狀態 in_progress / completed）
- `state.attendance`（scanned 狀態 + 出席率）
- `state.logs`（每次派遣、點名都有紀錄）

DemoClosureRail 的計數器是根據這些 state 真實計算，不是假的。

### 如果商品沒庫存怎麼辦？

庫存為 0 時 `+` 按鈕 disabled，系統不允許下單。  
配送閉環需要建立「新訂單」（`orders.length > INITIAL_ORDERS_COUNT`）才算完成。

### 機器人用什麼硬體控制？

App → bridge server（port 3202，LAN 自動偵測）→ USB Serial → Arduino UNO R4 WiFi  
→ L293D 馬達驅動 IC → TT 馬達  
M1+M2 控制驅動輪（前進後退轉向），M3+M4 控制清掃滾筒（正反轉）。

### 搖桿可以控制真實機器人嗎？

可以。右下角 FAB「🎮 手動遙控」→ 虛擬搖桿送出  
FORWARD / BACKWARD / LEFT / RIGHT / STOP，bridge 轉給 Arduino。  
韌體有 3 秒看門狗，放開搖桿自動停車。

### 沒有 Arduino 可以展示嗎？

可以。App bridge server 有 `DEMO_SIMULATE_HARDWARE=1` 模式，  
所有指令回傳 200 OK，展示閉環正常進行。  
接上實體機器人後，同一套操作即可控制真實硬體。

### 機器人顯示端怎麼連？

第二螢幕或 iPad 直接輸入：
```
http://<主控機 LAN IP>:5174/robot-display.html
```
`robot_app2.jsx` 透過 WebSocket 接收 bridge server 推送的情緒指令，  
動畫、顏色、文字依任務狀態自動更新。

## 現場備援 SOP

| 狀況 | 處理 |
|---|---|
| 網路慢 AI 不回應 | 等 20 秒出現 amber 橫幅「離線備援模式」，繼續念腳本，功能不中斷 |
| 相機拒絕授權 | 點「略過鏡頭，手動完成點名」，閉環照樣完成 |
| Arduino 未接 | Toast 顯示「無法送指令」，念「目前展示模式，實體機器人在後台待命」 |
| 不小心重整頁面 | `localStorage` fallback 自動恢復，若資料清空直接用 DemoClosureRail 重跑三步 |
| robot display 沒更新 | 確認 bridge server 跑著（`一鍵啟動展示.command` 視窗未關）；bridge 連線後自動恢復 |

```
馬達驅動     L293D：M1+M2 輪子 / M3+M4 清掃
Robot UI     robot_app2.jsx → /robot-display.html（WebSocket cue）

             DELIVERY_START DELIVERY_DONE
             SWEEP_ON SWEEP_OFF
             BROADCAST_START PATROL_START
看門狗       3 秒無指令 → Arduino 自動 STOP
```
