# App 1 學生一鍵啟動說明

## 第一次使用

1. 雙擊 `一鍵啟動展示.command`。
2. 如果電腦沒有 Node.js，視窗會自動開啟下載頁；安裝 Node.js 20 LTS 以上版本後，再重新雙擊一次。
3. 第一次啟動會自動安裝套件並建立 `.env.local`，需要網路，之後啟動會快很多。

## 每次展示

1. 雙擊 `一鍵啟動展示.command`。
2. 等瀏覽器自動開啟 `http://127.0.0.1:3201/#whiteboard`。
3. 學生照畫面按鈕走流程；沒有接硬體時會自動使用展示模式。
4. 展示結束後，回到啟動視窗按 Enter，或雙擊 `一鍵停止展示.command`。

## 老師或助教檢查

```zsh
npm run check:app1
pio run -e uno_r4_minima_app1_whiteboard_drive
```

## 實體 Arduino

學生展示不需要先接 Arduino。要測實體板擦機器人時，老師或助教再設定 `ARDUINO_PORT`，並用 `pio run -e uno_r4_minima_app1_whiteboard_drive -t upload` 上傳韌體。
