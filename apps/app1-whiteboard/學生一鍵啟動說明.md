# App 1 學生一鍵啟動說明

## 第一次使用

1. 雙擊 `一鍵啟動展示.command`。
2. 如果電腦沒有 Node.js，視窗會自動開啟下載頁；安裝 Node.js 20 LTS 以上版本後，再重新雙擊一次。
3. 第一次啟動會自動安裝套件並建立 `.env.local`，需要網路，之後啟動會快很多。

## 每次展示

1. 雙擊 `一鍵啟動展示.command`。
2. 等瀏覽器自動開啟 `http://127.0.0.1:3201/#whiteboard`。
3. 學生照畫面按鈕走流程。
4. 展示結束後，回到啟動視窗按 Enter，或雙擊 `一鍵停止展示.command`。

## 自動硬體偵測（不用手動設定）

腳本啟動時會自動判斷硬體狀態，學生不用做任何選擇：

| Arduino 狀態 | 腳本行為 | 上方狀態列 |
|------|----------|------|
| 已接 USB、正常運作 | 直接連硬體模式 | **綠色細線**（已連接） |
| 已接 USB、處於 DFU 模式（從未燒過或誤雙擊 Reset） | **自動燒錄正確韌體**後再連 | 燒錄完成後變綠色 |
| 沒接 USB | 自動切到展示模式 | **紫色「示範模式」** |

腳本也會自動釋放被其他 App 或殘留 process 佔住的 Serial port，學生不用手動開 Activity Monitor 殺 process。

## 老師或助教檢查

```zsh
# App1 完整檢查（lint + tests + build）
cd apps/app1-whiteboard && npm run check

# Demo 全流程播放測試
cd apps/app1-whiteboard && node scripts/demo-readiness-check.mjs

# 手動燒 firmware（學生用 .command 啟動時會自動燒，老師端可預先燒）
pio run -e uno_r4_minima_app1_whiteboard_drive --target upload
```

## 實體 Arduino

接上 UNO R4 Minima 後，腳本會自動偵測並進入硬體模式；沒接也能跑展示模式。
韌體 env：`uno_r4_minima_app1_whiteboard_drive`，由腳本在 DFU 模式時自動燒入。
