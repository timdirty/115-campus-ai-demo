# Student Demo Pitches

這份講稿給三隊上台前練習用。每隊都有 1 分鐘、3 分鐘、5 分鐘版本，可以依比賽時間縮放。

## 國小隊伍 1 - AI 自動板擦機器人

### 1 minute

大家好，我們是國小隊伍 1。我們的作品是「AI 自動板擦機器人」，它要解決的是：白板 AI 助教、教師決策、課堂紀錄與機器人指令展示。

展示時我們會照著三步驟：拍白板 -> 看決策 -> 送指令。第一步讓系統取得現場資料，第二步由 AI 或本機辨識做判斷，第三步把結果轉成機器人可以執行的指令。

硬體連動部分，我們預留 LEGO EV3 角色：「白板筆臂 / 板擦路徑展示」。沒有接硬體時也能用模擬模式完整展示；接上 EV3 後，會使用 `EV3_STATUS`, `EV3_CALIBRATE`, `EV3_PEN_DOWN`, `EV3_PEN_UP`, `EV3_DRAW_LINE`, `EV3_HOME`, `EV3_STOP` 等指令。

### 3 minutes

我們選這個題目，是因為校園裡有很多重複、即時、需要安全判斷的工作。AI 自動板擦機器人 把畫面、資料或感測訊號整理成學生和老師看得懂的任務流程。

這個作品的技術重點有三個。第一，前端是完整可操作的 app，不是只有簡報畫面。第二，系統有本機備援邏輯，AI 或網路不穩時仍能展示主要流程。第三，機器人指令已經整理成 catalog，未來接 EV3 時不用重寫作品。

我們現場會展示：拍白板 -> 看決策 -> 送指令。如果評審想看硬體，我們會說明 EV3 的角色是「白板筆臂 / 板擦路徑展示」，並展示指令如何從 app 送到 bridge，再到 EV3 或 Arduino。若沒有硬體，系統會啟用模擬模式，留下任務紀錄，證明流程仍然完整。

### 5 minutes

完整展示可以分成問題、解法、AI、硬體、備援五段。

問題：白板 AI 助教、教師決策、課堂紀錄與機器人指令展示。

解法：我們不是只做一頁展示，而是做成一個可以操作的校園工具。使用者從首頁進入後，可以依序完成 拍白板 -> 看決策 -> 送指令。

AI：作品會把輸入資料轉成可理解的建議。可以使用雲端 AI，也保留本機分析或 fallback，避免現場網路造成展示中斷。

硬體：EV3 指令已先規劃成 `EV3_STATUS`, `EV3_CALIBRATE`, `EV3_PEN_DOWN`, `EV3_PEN_UP`, `EV3_DRAW_LINE`, `EV3_HOME`, `EV3_STOP`。這代表 app 端、bridge 端、EV3 server 端可以用同一份指令語言溝通。

備援：如果相機、AI、EV3 或 Arduino 其中一個現場不穩，作品仍能開啟、操作、記錄任務，並用模擬模式說明接上硬體後的真實動作。
