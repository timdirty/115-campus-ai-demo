# ═══ 第一部分：通用硬體 & 啟動 ═══

## 一、整體架構

```
一台筆電（MacBook）
├─ App 1 AI 板擦   → Bridge :3201 → USB → Arduino UNO R4 Minima → L293D → M3+M4 (板擦輪)
├─ App 2 校園服務  → Bridge :3202 → USB → Arduino UNO R4 WiFi  → L293D → M1+M2 (驅動) / M3+M4 (清掃)
└─ App 3 心靈守護  → Bridge :3203 → USB → Arduino UNO R4 WiFi  → L293D → M1+M4 左 / M2+M3 右
                                                                ↘ WiFi → iPad robot-display.html
```

**三組完全獨立，不共用資料。**  
**沒有 Arduino 時，三組都自動走模擬模式，閉環照樣跑完。**

## 完整講稿（約 5-6 分鐘）

### 開場（同學 A，60 秒）

> 「大家好，我們是 AI 自動板擦機器人小組。」

> 「教室裡有一個常見問題：老師寫滿一面白板後，要決定哪些內容留下來、哪些可以擦——這件事很花時間。更重要的是，白板上很多孩子當下沒聽懂的內容，一旦被擦掉就消失了，回家也找不回來。」

> 「所以我們做的不只是擦白板，而是**讓白板成為孩子可以重複學習的材料**。整個系統的核心是學生視角的閉環：拍白板 → AI 解讀 → 繼續問 → 老師決策 → 存成複習材料，整個流程 30 秒內跑完。」

> 「現在請同學 B 操作。」

---

### 步驟 1：拍白板 + AI 整理（同學 B，90 秒）

📱 **操作：**
1. 白板頁按「**開啟**」（多顆攝影機時下拉選單自動出現）
2. 對準白板
3. 按「**整理**」

> 「這是 Google Gemini Vision，真實送圖給 AI，不是假動畫。」

*等待中（5-10 秒），畫面深色遮罩 + spinner，繼續說：*

> 「系統送出一張白板截圖給 Gemini，AI 正在讀取文字、判斷今天教了什麼、找出孩子需要練習的地方。」

*AI 回傳後：*

> 「右側出現兩個區塊——上方是 AI 用孩子聽得懂的話重新整理的學習目標和練習建議，下方是原始 OCR 文字。這不是翻譯，是重新組織成學生的學習視角。」

🎯 **評審會看：** 右側 AI 解讀不是固定文字，每次白板內容不同就會不同。

**備案（攝影機不行）：**
> 「我切換到上傳模式，效果完全一樣。」→ 按「**上傳黑板照片分析**」

---

### 步驟 2：問 AI 小老師（同學 C，60 秒）

📱 **操作：**
1. 按右下角綠色大按鈕「**問 AI 小老師**」
2. 跳到 chat 頁面
3. 連點底部快速回覆：「這是什麼？」→「舉個例子」→「出一題給我」

> 「學生不用打字也可以持續問。這五顆快速回覆讓不會打字的孩子也能跟 AI 一來一回，像跟老師聊天。每次回覆刻意控制在 1-3 句、不超過 60 字，孩子不會被大段文字嚇到。」

> 「而且左側始終顯示剛才白板分析的標題——AI 小老師知道今天在上什麼課，不是憑空回答。」

---

### 步驟 3：教師決策（同學 B，45 秒）

📱 **操作：**
1. 側欄點「**教師**」
2. 看到白板分成 A / B 兩區，旁邊標示「保留」或「建議清空」
3. 根據需要調整（按「保留」或「標記清空」）
4. 按「**確認送出**」

> 「AI 給的是建議，不是命令。老師在這裡可以調整——想留到下堂課的區塊改成保留，其他的才讓機器人去擦。**最終決定權永遠在老師手上**，這是我們刻意的設計。」

---

### 步驟 4：派機器人（同學 C，45 秒）

📱 **操作：**
1. 側欄點「**機器人**」
2. 按「**派擦除任務**」

*有 Arduino（UNO R4 Minima）時：*  
📱 USB Serial 送指令 → L293D → M3+M4 馬達轉動，板擦沿 A/B 區塊路徑移動

> 「指令透過 USB 序列送到 Arduino UNO R4，再由 L293D 馬達驅動模組控制兩顆 TT 馬達——M3 和 M4——沿著白板標記好的 A/B 區塊路徑移動。白板上對應的區塊會出現 ✓ 覆蓋層，任務 log 留下時間戳。」

*沒有 Arduino 時：*
> 「目前展示模式——指令有紀錄，接上實體機器人後同一條指令就控制真實硬體。」

**EV3（若有）：**
> 「我們也預留了 LEGO EV3 接口，指令是 `EV3_PEN_DOWN`、`EV3_DRAW_LINE`、`EV3_HOME`，板擦路徑展示可以直接對應到 EV3 的筆臂動作。」

🎯 **評審會看：** 白板上的 ✓ 覆蓋層 + 任務 log

---

### 步驟 5：紀錄本 + 學習單（同學 C，30 秒）

📱 **操作：**
1. 側欄點「**紀錄本**」→ 這節課的白板分析已自動存入
2. 側欄點「**學習單**」→ 從同一筆紀錄自動生成 4 選項小測驗，學生可直接作答

> 「整理完白板、擦完白板，這節課的重點自動變成了學習單。孩子可以馬上作答複習——一個白板分析串起六個頁面的完整教學閉環。」

---

### 收尾（同學 A，30 秒）

> 「我們這套系統最特別的地方是**學生視角的閉環**：拍白板 → AI 解讀 → 繼續問 → 老師決策 → 存成複習材料。不是全自動擦白板，而是 AI 輔助、老師確認、孩子受益——每一步都有人在迴路，安全、可控、真實可用。謝謝評審。」

## App 1 評審 Q&A 速查

| 問題 | 回答要點 |
|---|---|
| AI 怎麼辨識白板？ | Gemini Vision 讀字 → 判斷主題 → 抽出目標 → 用孩子語言重寫。5-10 秒回。四層自動 fallback（flash-lite → 2.0-flash → gemma → 2.5-flash） |
| 機器人會不會亂擦？ | 不會。AI 只給「左區 / 右區建議」，老師確認才送指令。白板切三個校準區塊，固定路徑移動 |
| 白板內容會外洩嗎？ | Canvas 截圖在本機處理，只有按「整理」才送 Gemini。關 Gemini 用本機模式，圖片完全不出去 |
| 沒有固定攝影機限制大嗎？ | 第一階段是區塊式決策，不依賴定位。第二階段才加白板座標校正，本次展示是完整的第一階段 |
| 這跟普通板擦機器人差在哪？ | 市面上的是全自動固定路徑，不判斷哪裡要留。我們加了 AI 辨識和老師確認層，而且擦完同時完成課堂筆記 |
| Arduino 是什麼？ | UNO R4 Minima，可程式化微控制器。用 PlatformIO 編譯韌體，USB Serial 傳指令，L293D 驅動馬達 |
